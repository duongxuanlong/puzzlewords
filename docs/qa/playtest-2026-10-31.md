# Playtest 2026-10-31 — web build, levels 1–4

- Build: `npm run build:web` (web-mobile, release), served by `tools/serve.js`, opened in the Claude desktop browser pane at 768x1600 (desktop user agent; the pane's mobile emulation sends mouse events that Cocos ignores under a mobile UA). Build id 0.1.0 + 76966b7 with the UI work uncommitted on top.
- Method: the `testing` skill checklist. Drags are real pointer drags (start → end, few intermediate moves, so routing is exercised); model state read back through the page after each step.
- Result: **all functional checks pass**. Two expected gaps (persistence, settings) are milestone 2. Polish items fixed in the same session are listed at the end.
